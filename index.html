طريقة الرفع على GitHub
  1. حمّل ملف ZIP ثم فك ضغطه على جهازك.
  2. أنشئ مستودعاً جديداً على github.com.
  3. اختر Add file ثم Upload files وارفع الملفات (أو ارفع الحزمة كاملة عبر Git).
  4. فعّل Pages من Settings إن كان التطبيق HTML.
