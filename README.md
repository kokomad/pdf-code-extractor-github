# مستخرج الأكواد من PDF

تطبيق جوال (HTML5) يستخرج ملفات الأكواد من PDF أو Markdown ويجمعها في ملف ZIP جاهز للرفع على GitHub.

## التشغيل على GitHub Pages
1. ارفع هذه الملفات إلى مستودع جديد (الفرع main).
2. من Settings ثم Pages اختر Source: GitHub Actions.
3. بعد انتهاء الـ workflow يظهر رابط التطبيق في تبويب Actions.
